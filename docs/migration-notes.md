# 数据迁移与兼容

当前持久化版本为 **223**。启动和备份恢复共用 `packages/shared/stateMigration.ts`；本轮仓库收敛不添加迁移。

| 版本 | 既有行为 |
| --- | --- |
| 216 | 一次性清除更旧配置中的服务商、凭据和失效引用 |
| 217 | 归入三平台并合并共享目录，修正端点与旧 UA／检测状态 |
| 218 | 删除主动网络搜索配置，保留历史聊天内容 |
| 219 | 初始化模型测试的独立模型和提供商选择 |
| 220 | 初始化助手的独立模型选择 |
| 221 | 规范化模型测试并发数 |
| 222 | 初始化目录同步及用户删除记录 |

已有有效新设置优先；重复执行不重置用户设置。旧数据库中的只读工具、知识库或翻译记录与兼容类型不再触发已删除功能。不能因字段名属于旧功能就删除历史内容。

Android 凭据转换与业务版本分离：安全存储成功后才从普通状态移除明文。桌面凭据存储迁移留待后续，当前保持兼容。

备份容器不变：独立 salt／nonce、Argon2id 固定版本参数和 AES-256-GCM；认证及内容校验先于恢复。含凭据须密码，不含凭据为默认。CCswitch 仍要求用户确认，取消不会保存。
