# 数据迁移与兼容

当前持久化版本为 **223**。启动和备份恢复共用 `packages/shared/stateMigration.ts`；启动及恢复会删除已移除模型测试的选择与并发设置，不增加持久化版本；主窗口启动时删除旧指纹缓存，不修改聊天和服务商。

| 版本 | 既有行为 |
| --- | --- |
| 216 | 一次性清除更旧配置中的服务商、凭据和失效引用 |
| 217 | 归入三平台并合并共享目录，修正端点与旧 UA／检测状态 |
| 218 | 删除主动网络搜索配置，保留历史聊天内容 |
| 219 | 历史版本号，初始化步骤已移除 |
| 220 | 初始化助手的独立模型选择 |
| 221 | 历史版本号，初始化步骤已移除 |
| 222 | 初始化目录同步及用户删除记录 |
| 223 | 从旧默认助手迁移全局流式模式，删除助手级 streamOutput 和旧分析开关 |

已有有效新设置优先；重复执行不重置用户设置。旧数据库中的只读工具、知识库或翻译记录与兼容类型不再触发已删除功能。不能因字段名属于旧功能就删除历史内容。

Android 凭据转换与业务版本分离：安全存储成功后才从普通状态移除明文。桌面沿用 v0.1.37 的系统凭据库迁移，同样在安全写入成功后清除明文，失败处理见 [隐私说明](privacy.md)。

备份容器不变：独立 salt／nonce、Argon2id 固定版本参数和 AES-256-GCM；认证及内容校验先于恢复。含凭据须密码，不含凭据为默认。已保存的服务商与凭据继续可用。
