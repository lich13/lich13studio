# 数据与隐私

本说明对应 lich13studio 0.1.39 的现有实现。

## 本地数据

助手、话题、聊天记录、服务商和模型目录保存在设备中。Android 数据在应用私有目录，API Key 与 WebDAV 凭据通过 Keystore 加密保存，普通持久化只存引用，系统自动备份关闭。桌面端（v0.1.37 起）将 API Key、WebDAV 密码与认证请求头写入系统凭据库（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），普通持久化只存引用；只有安全写入成功后才清除明文，失败时保留原数据，迁移可重复执行。若系统凭据库不可用（例如无 Secret Service 的 Linux 环境），桌面端保持原有本地明文保存并在日志中警告。

本地日志统一经过 `packages/shared/logSanitizer.ts`，过滤凭据字段、请求／响应正文及已识别的敏感文本。日志脱敏不能替代提交报告前的人工检查；不要公开原始数据库、用户日志或含凭据的备份。

## 网络边界

- 聊天使用用户配置的提供商、地址和凭据。消息、附件和必要助手提示会发给该提供商。
- WebDAV 仅使用用户配置的服务器；启用备份后由用户设置决定执行时间。
- 模型目录与 CLI 版本使用公开上游来源；版本检查使用本项目 GitHub Releases。请求不携带提供商凭据、聊天或助手配置。
- 应用自有分析、遥测和隐藏上传已移除。错误诊断使用本地规则，不向其他模型发送错误内容。依赖安装中的 Scarf 脚本执行被显式禁用。
- 开发者手动运行国际化脚本时，会使用开发者自行配置的接口处理文案；它不是应用运行时功能。

## 备份与恢复

普通备份默认排除凭据。包含凭据必须设置密码，采用 Argon2id／AES-256-GCM；每份独立生成随机 salt 和 nonce。密码不保存。认证及内容校验完成后才恢复，桌面与 Android 共用版本化容器。

升级和恢复旧备份会清理已移除功能的专属设置。主窗口启动时删除旧指纹缓存；若被旧窗口占用或删除失败，提示关闭应用后重启重试。服务商、凭据、聊天记录、助手、模型目录及备份保留。

## 反馈

漏洞使用 [私密报告](../SECURITY.md)。普通问题提交到 [本项目 Issues](https://github.com/lich13/lich13studio/issues)，只附脱敏后的最小复现。
