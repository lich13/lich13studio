# 数据与隐私

本说明对应 lich13studio 0.1.35 的现有实现。

## 本地数据

助手、话题、聊天记录、服务商和模型目录保存在设备中。Android 数据在应用私有目录，API Key 与 WebDAV 凭据通过 Keystore 加密保存，普通持久化只存引用，系统自动备份关闭。桌面目前仍以普通本地状态保存凭据；本轮未改变该格式，不宣称桌面凭据已加密。

本地日志统一经过 `packages/shared/logSanitizer.ts`，过滤凭据字段、请求／响应正文及已识别的敏感文本。日志脱敏不能替代提交报告前的人工检查；不要公开原始数据库、用户日志或含凭据的备份。

## 网络边界

- 聊天与 ModelTrace 使用用户配置的提供商、地址和凭据。消息、附件和必要助手提示会发给该提供商。
- WebDAV 仅使用用户配置的服务器；启用备份后由用户设置决定执行时间。
- 模型目录、CLI 版本、指纹库使用公开上游来源；版本检查使用本项目 GitHub Releases。请求不携带提供商凭据、聊天或助手配置。
- 应用自有分析、遥测和隐藏上传已移除。错误诊断使用本地规则，不向其他模型发送错误内容。依赖安装中的 Scarf 脚本执行被显式禁用。
- 开发者手动运行国际化脚本时，会使用开发者自行配置的接口处理文案；它不是应用运行时功能。

## 备份与导入

普通备份默认排除凭据。包含凭据必须设置密码，采用 Argon2id／AES-256-GCM；每份独立生成随机 salt 和 nonce。密码不保存。认证及内容校验完成后才恢复，桌面与 Android 共用版本化容器。

CCswitch 完整链接仅在内存中排队，确认前不持久化，附带的 usageScript 不执行。链接可能包含凭据，不应复制到公开日志或报告。现有链接接受范围保持不变。

## 反馈

漏洞使用 [私密报告](../SECURITY.md)。普通问题提交到 [本项目 Issues](https://github.com/lich13/lich13studio/issues)，只附脱敏后的最小复现。
