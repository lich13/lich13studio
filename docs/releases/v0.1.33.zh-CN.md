# lich13studio v0.1.33

发布日期：2026-10-08

## 新增功能

- 模型测试先独立执行第一组。最高模型匹配概率达到 99% 时提前完成，无需继续请求剩余组；未达到时再执行其余两组。
- 后两组沿用已有并发设置：并发为 1 时顺序执行，为 2 或 3 时最多同时执行两组。
- 提前完成后显示“已提前完成”，其余组显示“无需继续”。参与分析的组数仍在结果区展示。

## 修复问题

- 提前完成会取消其余连接、排队请求和重试等待，清理结束后释放后台任务。迟到数据和未完成样本不会进入结果。
- 修复类型导入、冗余断言、正则写法和异步回调相关 lint 问题；CI 和发布构建新增完整代码检查门禁。
- 清理旧文档和测试样例中的个人目录，改用通用样例路径。

## Android 兼容性

- Android 与桌面使用相同的提前完成规则；继续支持离开页面后后台执行、通知停止及返回查看结果。
- 本次不增加系统权限，不改变 Android 最低版本和 ARM64 架构要求。

## 隐私与数据处理

- 测试继续直连用户选择的提供商，不新增代理、遥测或上传入口。提前取消前已发送的请求仍可能产生用量。
- 保留输出保护、有限重试、不发送思考参数及无模型请求超时的规则；测试样本和结果不写入聊天记录。

## 升级与备份

- 数据迁移版本保持 223。聊天、助手、提供商、模型目录和全局设置保持原样，升级前可保留本地备份。

## 验证范围

- 回归覆盖提前完成阈值、请求调度、连接清理、失败重试、取消和后台状态；使用隔离模拟接口，不调用真实模型。
- Android API 31／36 设备回归覆盖真实页面提前完成、离页返回和后台任务释放；完整检查与构建结果见本版本 GitHub Actions。

## 已知限制

- 匹配概率是指纹库内的统计归因结果，不能证明提供商实际运行的模型身份。
- 首组样本不足或匹配概率未达到阈值时，仍可能执行全部三组；提前结束不会降低已有单组输出保护标准。
- 本轮不包含 Windows 界面、Android 实体手机和真实模型接口验收。
