# lich13studio v0.1.41

## 精简与性能

- 清理残留死代码、废弃图像补丁与 20 余项冗余依赖，将 `code-languages` 收敛为扁平扩展名列表，移除无引用的终端命令表、空转状态代理与后台定时轮询。
- 将 `core-js` 全量兼容包收窄至 Android 12（Chromium 91）／Safari 15 实际缺失的 ES2022–ES2024 子集（首屏 `tauri-shim` 体积下降约 67%），统一 KaTeX 单例入口并仅保留 `.woff2` 字体，将 CodeMirror 语言与主题拆分为按需分包加载。
- 优化流式 Markdown 渲染与代码块查看器：补齐 `CodeBlock`/`Table` 精确 `memo` 与原子状态订阅，流式长消息前置块分段缓存，展开态代码块跳过虚拟滚动与逐行尺寸监听；优化历史搜索初筛与增量内容哈希 Token 缓存。
- 降低原生层 CPU、内存与磁盘占用：凭据存储增加已落盘快照去重以消除日常会话期间重复加密写入；本地与 WebDAV 备份/恢复全部移入后台阻塞线程池并采用流式文件写入，合并加密备份解密与解压，附件读取改用原生二进制 IPC，合并流式 HTTP 分片确认与数据库块写入频率，并剔除 Android 原生库中的桌面专属依赖。

## Android 界面重排版与跨端修复

- 重构 Android 端界面排版：将原三层堆叠顶栏压缩为紧凑双层顶栏（横屏自动合为单行）并补齐搜索、显示设置与新话题入口，常驻保留原生双选择器；修复恢复桌面备份后抽屉话题列表隐藏问题；消息区全宽化并常驻显示轻量矢量操作栏；将设置页与数据设置双层下拉框替换为横向胶囊导航栏，并在移动端显示设置中补齐字号、气泡样式与思考自动折叠控制。
- 修复本地备份列表时间显示错误与默认下载目录无法列出备份的问题，修复 Windows／Linux 关闭主窗口最小化到托盘失效与快捷助手残留进程问题，修复删除服务商后空白页、消息暂停与后台切页时的流式块刷盘竞态，以及 Android 前台服务快速停止崩溃、长流式唤醒锁续期、凭据读写并发锁与导出临时文件目录隔离问题。
- 持久化版本保持 223，已有服务商、系统凭据、助手、聊天记录、模型目录、桌面端 Obsidian 导出与备份格式保持兼容。
