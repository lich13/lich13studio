# lich13studio v0.1.30

发布日期：2026-10-02

## 新增

- 普通聊天、快捷助手和助手窗口支持流式与非流式请求切换，默认使用流式。
- Android 数据设置支持通过系统文件选择器执行本地备份与恢复，凭据继续由系统密钥库保护。
- Android 继续接管 `ccswitch://` 导入链接，并保留聊天、测试、设置和后台任务的移动端入口。

## 修复

- 修复 Android 模型与提供商选择器在重绘时关闭、闪烁或丢失选择的问题。
- 修复显示设置颜色控件在窄窗口中错位和溢出的问题。
- 统一非流式请求的完整结果提交，避免界面收到半截内容。
- 请求模式在发送时冻结，切换页面或选择器不会改写正在执行的请求。

## 隐私与兼容

- 移除应用自有分析、启动统计、Token 上报和更新上报。
- 模型请求只发送到用户配置的服务商地址；公开目录和版本检查请求不携带聊天内容或凭据。
- 日志和本地追踪只保留脱敏元数据，不保存提示词、消息正文、Key、Authorization、Cookie 或响应正文。
- 保留聊天、助手、服务商、模型目录和历史数据。

## 升级与备份

- 数据迁移版本为 223，启动和备份恢复均可重复执行。
- Android 默认备份不包含凭据；需要携带凭据时必须使用密码保护备份。

## 已验证

- Renderer 测试 508 项、升级迁移测试 219 项、Rust 测试 24 项全部通过。
- 类型检查、国际化检查、格式检查、OpenAPI 检查、隐私扫描和 Web 构建通过。
- macOS 应用签名结构检查通过并安装到 `/Applications/lich13studio.app`；已确认旧聊天、助手、服务商和模型配置仍在。
- Android ARM64 APK 已生成，版本 0.1.30、最低 API 31，APK v2 签名验证通过。

## 已知限制

- 当前主机没有可用的 Android API 31/36 模拟器或实体设备，因此移动端点击、锁屏后台和系统返回流程未完成实机验收。
- 当前主机没有 Windows Visual Studio 构建环境，本轮未生成 Windows 安装包。
- macOS 使用本地签名，未执行 Apple 公证；本轮使用隔离接口验证请求模式和 Android 文件选择流程，不代表真实服务商模型可用性。
