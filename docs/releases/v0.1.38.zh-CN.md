# lich13studio v0.1.38

## 功能调整

- 移除 CC Switch 链接接管及服务商导入功能。macOS、Windows 与 Android 不再注册或接收该导入协议；服务商可继续在设置中手动添加。
- 移除模型测试页面、聊天入口和 Android 测试导航，以及指纹分析、测试请求、自动同步和内置指纹库。
- 升级时清理旧模型测试设置及专属缓存，恢复旧备份也不会重新启用这些功能。

- 删除 Electron 主进程、preload、旧 WebView 容器和更新器，以及专属依赖、补丁与构建配置。保留 React 界面，改用普通 Vite 构建，原生能力继续由 Tauri／Rust 提供。

## 数据与兼容

- 保留已有服务商、凭据、助手、聊天记录、模型目录和备份，正常聊天的模型选择与地址处理保持可用。
- 持久化版本保持 223，备份格式和系统凭据存储方式不变。
- Android 底部导航保留聊天和设置，正常聊天继续支持后台任务通知及停止操作。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
