# lich13studio v0.1.35

发布日期：2026-10-15

## 修复与清理

- 错误诊断改用本地规则。打开错误消息或查看诊断时，不再自动调用其他模型，也不再发送错误正文、连接信息或代理凭据。
- 补齐备份密码、API Key 数组、系统提示词及嵌套错误的日志脱敏，移除 OAuth 和模型请求中的原始响应日志。
- 清理已移除功能留下的 RAG 实现、专用依赖、失效文案、资源和补丁，保留仍在使用的构建入口、托盘图标及历史数据兼容代码。
- 更新中文说明、问题反馈入口与第三方许可说明，启用本项目的私密漏洞报告入口。

## 构建与 Android 兼容性

- 本地与 CI 共用检查入口，统一 Node 版本来源，补充 Rust 格式、clippy 和测试检查。
- GitHub Actions 固定到提交，默认只读权限，仅发布作业申请必要写权限。
- 保持 Tauri 运行时、Android 12 及以上和 ARM64 要求、应用签名及现有权限不变。Android 与桌面共用本轮隐私修正。

## 隐私与数据处理

- 禁止依赖安装阶段执行 Scarf 统计脚本；公开目录同步、用户配置的模型请求及 WebDAV 保持原有边界。
- 保留聊天、助手、服务商、模型目录和设置。持久化版本仍为 223，备份格式与 CCswitch 导入行为不变。
- 桌面凭据仍保存在普通本地状态中；Android 继续使用 Keystore。包含凭据的备份仍须设置密码。

## 升级与备份

- 使用对应平台安装包覆盖升级即可。升级前可通过数据设置保留本地备份。
- 本版不要求重新导入服务商，不更换当前模型或请求模式。

## 验证范围

- 通过日志脱敏、本地错误诊断、导入取消、备份恢复和迁移幂等性回归，以及静态、类型、国际化、隐私和构建检查。
- Rust fmt、clippy 和原生测试通过；完整前端、Android API 31／36 回归及三平台构建结果见对应 GitHub Actions。
- 本轮不调用真实模型，不消耗模型 API 额度。

## 已知限制与待用户验收

- 第三方依赖仍有存量安全审计告警，CI 按报告模式展示；本版不表示所有第三方漏洞已修复。许可文件缺口及来源说明见仓库 NOTICE。
- 桌面凭据安全存储迁移、CCswitch 链接长度和队列上限留待后续版本。
- 请检查原有聊天与设置是否保留，错误详情是否正常显示，以及导入取消、备份恢复是否保持原有行为。实机界面和业务操作仍待用户验收。
