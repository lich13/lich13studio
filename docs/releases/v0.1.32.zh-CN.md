# lich13studio v0.1.32

发布日期：2026-10-05

## 新增

- 检查到新版本时直接打开对应版本的 GitHub Release 页面；更新通知和托盘入口使用同一安全地址。
- Android 首页的模型和提供商选择改用系统原生列表，模型先选、提供商后选，保留现有选择。

## 修复

- 修复快捷助手标题、模型、提供商和新建话题按钮被挤成多行后裁剪的问题，恢复单行横向布局并支持窄窗口滚动。
- 修复模型与提供商下拉层在 Android WebView 中因键盘、Portal 或重绘而瞬间关闭的问题。
- 修复更新地址可能落到安装包下载链接或不安全链接的问题。

## 隐私与兼容

- 更新检查只访问 GitHub 公开 Release 信息，不携带服务商凭据、聊天内容或助手配置。
- Android 选择器不新增权限，不改变现有凭据存储、备份和模型请求行为。
- 保留聊天、助手、服务商、模型目录和历史数据；不重新引入搜索、MCP、健康检测或遥测。

## 升级与备份

- 数据迁移版本保持 223，无新增用户数据迁移。升级前请保留本地备份。
- 检查到更新后需要在 GitHub Release 页面手动选择适合设备的安装包；应用不会自动下载或安装。

## 已验证

- 已覆盖 Release 地址校验、同一版本地址生成、平台安装包信息保留，以及模型和提供商选择的独立状态处理。
- 已加入 Android 原生选择器的点触、异常值、不可用项和重绘回归覆盖；最终 API 31/36 模拟器结果以 CI 发布检查为准。

## 已知限制

- Android 原生列表的系统外观由设备 WebView 和系统主题决定。
- 本轮不调用真实模型；发布构建、签名和设备覆盖以 GitHub Actions 结果为准。
