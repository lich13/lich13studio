# lich13studio v0.1.42

## 修复与稳定性

- 修复 Android 端 `MainActivity` 销毁收尾时 Tauri 事件循环直接触发 `std::process::exit(0)` 的问题，改为保持原生事件循环存活并在缓存进程重新打开主界面时自动重建主窗口，同时消除 Android API 31 设备自动化回归测试收尾阶段的进程退出异常。
- 修复 Android 原生插件在主 Activity 重建后仍持有旧 Activity 引用的问题，将存储、通知权限查询与后台服务统一切换至 `applicationContext`，UI 与任务跳转动态绑定当前活跃 Activity。
- 收紧 Android WebView 销毁时的渲染器优先级降级、窗口内边距监听解绑与后台任务事件分发保护，升级 `wry` 修复 Android 销毁后事件派发竞态。
- 持久化版本保持 223，已有服务商、系统凭据、助手、聊天记录、模型目录与备份格式保持兼容。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
