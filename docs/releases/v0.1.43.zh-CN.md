# lich13studio v0.1.43

## 功能与交互升级

- **Android 原生接管 `cc-Switch` 连接**：在 Android 端恢复并增强 `ccswitch://v1/import` 深度链接接管（桌面端不注册该协议以免抢占本机 CC Switch），完整兼容冷启动、后台热唤醒与缓存进程重建主窗口生命周期，同时在引导页与服务商设置页提供粘贴导入入口；解析器支持多端点取首项、`apiFormat` 协议优先级与内联 Base64 `config`（Claude、Codex、Grok Build 等），经打码确认后直接写入 Android Keystore 并自动完成引导。
- **Android 返回键与浮层栈修复**：收口单顶层路由并兼容主 Activity 重建后的系统返回键分发，修复 `TopView` 弹出栈返回与取消回调，使全局搜索子页面、弹窗与确认框按视觉层级逐层回退，不卡死等待 Promise、不误退桌面或误退全屏；补齐移动端全局搜索全屏布局与关闭入口，并过滤输入法组合态下的 `Escape` 误触。

## 性能优化与精简治理

- **前端渲染与首屏瘦身**：修复 `MessageBlockRenderer` 流式输出期间订阅全量消息块引发的全表重渲染风暴；剥离首屏同步 `zod`、Shiki 核心与重型弹窗依赖，将 Shiki 切换至纯 JS 正则引擎移除 Oniguruma WASM，大幅压降主窗口冷启动静态 JS 体积；优化流式 Markdown `\[...\]`/`<svg>` 增量切分与 $O(N)$ 公式扫描、全局搜索纯文本快路径及小体积图片 Token 估算。
- **原生宿主与存储降载**：附件写入、文件保存、窗口截图与备份恢复 IPC 切换至桌面端原生二进制载荷（`InvokeBody::Raw`）与 Android 端紧凑 Base64 载荷，配合 `Zeroizing` 编码头消除 JSON 数字数组内存膨胀；WebDAV 上传（含显式 `Content-Length`）、下载与未加密便携备份改走临时文件流式读写；补齐崩溃中断恢复回滚（`restore-previous-*`）与启动孤儿临时目录自洁，增加非活跃话题 Redux LRU 淘汰与 Dexie 事务内原子附件引用计数扣减。
- **历史残留深度清理**：移除 50+ 个零引用历史死文件、废弃子树、死 IPC 命令、孤立依赖与未引用多语言命名空间，将 `FallbackFavicon` 改为纯本地首字母徽章消除隐式第三方图标探测请求。持久化版本保持 223，完全兼容既有数据与备份。
