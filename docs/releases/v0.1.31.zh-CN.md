# lich13studio v0.1.31

发布日期：2026-10-05

## 新增

- 主聊天输入工具栏使用单个 Waves 图标切换流式和非流式请求，默认流式；设置自动保存，快捷助手跟随主面板，不再显示重复入口。
- 指纹库同步支持固定提交的同版本快速检查，并在 GitHub API 网络错误、超时或限流时使用官方 Git HTTP 分支查询和同提交原始文件回退。

## 修复

- 修复模型测试指纹库同步失败时无法区分网络、超时、限流、缓存和数据校验错误的问题。
- 修复同步请求超时未被可靠终止、失败冷却时间不清晰及重复下载的问题。
- 修复模型测试页状态提示，成功检查会显示“已是最新”或“已更新”，失败时继续使用最近有效指纹库。

## 隐私与兼容

- 指纹库更新只访问 GitHub 官方公开内容，不携带服务商凭据、聊天内容或模型请求数据；同步缓存独立于聊天数据库和备份。
- 保留现有聊天、助手、服务商、模型目录和历史数据；ModelTrace 仍不发送思考参数、工具或模型请求超时字段。
- 继续移除 MCP、网络搜索、健康检测、手机导出和应用自有遥测。

## 升级与备份

- 数据迁移版本保持 223，无新增用户数据迁移。
- 升级前请保留本地备份。同步失败时应用继续使用最近有效库或内置库，不影响聊天使用。

## 已验证

- Renderer 测试 510 项、升级迁移测试 222 项通过；指纹库同步专项测试 50 项和 Waves 按钮测试 1 项通过。
- 类型检查、国际化检查、严格硬编码检查和格式检查通过；格式检查仅保留一个既有的类名排序提示。
- 已核对 GitHub 官方固定提交与内置指纹库的兼容哈希，验证同版本短路、Git HTTP 回退、限流状态和缓存保留路径。

## 已知限制

- 本轮本地 Rust 测试受 devhost Cargo 缓存中 cc-1.2.60 缺失源文件阻塞，未据此判定产品代码失败；Rust、原生构建和三平台发布构建需以 GitHub CI 结果为准。
- 本轮未调用真实模型，不代表服务商接口可用性；Android、Windows 和 macOS 安装验收待发布构建完成后核对。
