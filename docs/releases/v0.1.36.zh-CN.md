# lich13studio v0.1.36

发布日期：2026-10-15

## 修复问题

- 修复 macOS 开机登录时，已开启“静默启动”却仍显示主界面的问题。应用现在从正确的 Apple Event 参数读取登录启动标记。
- 登录启动且开启静默时仅保留托盘；前端就绪、延迟显示兜底及重复登录启动不会唤醒主窗口。
- 主动从 Finder、Dock、托盘打开应用，或通过 CCswitch 导入服务商时，主窗口仍正常显示。静默启动不再依赖系统登录项的隐藏属性。

## 平台兼容性

- 本次启动修复针对 macOS，保留现有登录项注册方式及窗口状态恢复逻辑。
- Windows 和 Android 保持原有启动行为；Android 继续支持 Android 12 及以上、ARM64。

## 隐私与数据处理

- 不新增网络请求、权限、设置或数据迁移，不读取或上传模型凭据。
- 保留聊天、助手、服务商、模型目录及设置；持久化版本仍为 223，备份格式和 CCswitch 导入行为不变。

## 升级提示

- 使用对应平台安装包覆盖升级即可，无需重新配置开机启动或重新导入服务商。
- 升级前可通过数据设置保留本地备份。

## 验证范围

- 增加原生 Apple Event 参数读取回归，覆盖登录启动、缺失或错误参数、静默开关、延迟显示、重复启动和主动打开。
- 本机执行受影响的 Rust 格式、编译及测试；完整回归和三平台构建结果见对应 GitHub Actions。
- 本轮不调用真实模型，不消耗模型 API 额度。

## 已知限制与待用户验收

- 自动测试验证事件解析和窗口显示策略，不代替实际注销或重启后的系统登录验收。
- 请开启开机启动及静默启动后重新登录，确认只保留托盘；主动打开应用应正常显示主窗口。
- 关闭静默启动后再次登录，确认主窗口正常显示。
