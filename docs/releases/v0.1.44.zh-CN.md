# lich13studio v0.1.44

## 凭据隔离与安全加固

- **桌面端彻底移除系统钥匙串弹窗**：移除桌面端 `keyring` 系统凭据库调用，将服务商 API Key、认证请求头与 WebDAV 密码保存在应用数据目录（普通备份 `Data/` 目录之外）的本地 `0600` 隔离文件 `credentials.json`（临时文件 `sync_all` + `rename` 原子替换），WebView 普通持久化仅保存引用，保留导入失败回滚与双窗口合并契约，彻底根除 macOS ad-hoc 重装后的钥匙串授权弹窗；Android 继续使用系统 Keystore。
- **零弹窗升级自愈与备份脱敏加固**：升级首次启动不回读旧系统钥匙串，自动将未命中的历史 `lich13-secret:*` 引用按字段类型安全置空，并在主窗口给出受影响服务商与 WebDAV 一次性跳转重填提示（跨窗口启动不丢失通知）；扩充普通 `.zip` 备份脱敏规则覆盖 `privateKey`、`*_API_KEY` 及历史退役切片并在状态清洗阶段统一移除退役切片。
- **原生出站网络与重定向防护**：原生 HTTP 客户端固定直连已校验 IP（禁用环境代理绕过），对用户服务商与 WebDAV 请求强制同源重定向校验并拦截协议降级，消除跨源重定向泄露 `x-api-key` 等自定义认证头的风险。

## 性能优化与一致性修复

- **备份加解密降存与恢复事务强绑定**：加密备份采用 `AeadInPlace` 原位加解密消除双倍缓冲分配，容器校验改用流式结构检查降低内存峰值；恢复解包直接绑定 `restoreId` 并在提交与回滚阶段严格校验，WebDAV 流式 `PUT` 支持受控逐跳重传并仅接受最终 `2xx` 响应，修复 `state.json` 异常读取误清空其他配置的问题。
- **前端渲染与搜索降阶**：移除 `rehype-mathjax`（旧配置平滑映射至 `KaTeX`）与 `iconfont` 字体，前端产物净减约 `1.75 MiB`；流式 Markdown 补齐跨块与超长单行增量状态检查点将扫描复杂度降至 $O(N)$，消除消息分组浅拷贝引发的全列表重渲染，页内搜索改为单游标匹配并在流式更新中保持当前命中位且不抢夺滚动。
- **双窗口与流生命周期一致性**：快捷窗口切换为只读持久化存储适配器并按需拉取迁移快照，杜绝启动写回覆盖主窗口最新配置；发送入口等待首条消息落库成功后再按编辑代次清理草稿并阻止同话题并发重交；删除/清空消息与话题及停止生成时严格在 Dexie 事务成功后同步 Redux 并将未完成工具标记为 `cancelled`，补齐未提交草稿附件与被替换消息块的物理回收。

## 架构精简与界面治理

- **全栈减法清理**：拍平 `packages/aiCore` 多层插件注册空壳为直连 Vercel AI SDK 执行器，内联 `DbService` 纯转发层并收敛活跃话题单一事实源，下线未接入 CI 的冗余脚本与孤立前后端依赖。
- **界面与细节修复**：修复 `ErrorBlock` 错误翻译与服务商跳转短路、快捷窗口强制中文语言与样式表管理缺失、思考动效 `transition` 语法及未定义 CSS 变量，统一数值列与时间计数的 `tabular-nums` 等宽排版。

## 升级说明与安装包

- 从 v0.1.37–v0.1.43 桌面版升级后，首次启动若提示历史钥匙串引用已置空，请重新填写一次 API Key / WebDAV 密码，或直接恢复升级前导出的 `.lich13backup` 加密备份；此后后续升级与覆盖重装均不再需要重填或授权钥匙串。
- 提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
