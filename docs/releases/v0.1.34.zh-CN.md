# lich13studio v0.1.34

发布日期：2026-10-14

## 修复问题

- 快捷助手恢复紧凑单行顶栏。新话题按钮固定在最右侧，标题、模型和提供商按窗口宽度收缩，长名称以省略号显示，不再把操作按钮挤出窗口或产生横向滚动条。
- 修复 macOS 已开启静默启动却仍显示主界面的问题。通过系统登录启动事件识别来源，统一前端就绪、延迟显示、重复启动和 Dock 唤醒的处理。
- 静默启动时只恢复窗口尺寸和位置；全屏或最大化状态在首次打开主窗口时恢复。主动打开应用、托盘操作和 CCswitch 导入仍可唤醒主界面。
- 快捷助手继续使用主面板保存的全局流式设置，不增加独立开关。

## 构建与 Android 兼容性

- 更新 Node.js LTS、pnpm、TypeScript 检查器和测试工具，并修正相关类型声明及依赖补丁格式。Studio 保留与现有构建工具兼容的 Vite 7。
- Android 使用兼容的 Gradle 8.14.6、AGP 8.11.2 和 Kotlin 2.2.21 组合；最低系统版本、ARM64 要求和签名保持不变。
- Rust 开发与检查使用 stable 工具链。本轮未更换 Tauri 运行时，也未增加系统权限。

## 隐私与数据处理

- 不新增遥测、代理、上传入口或模型请求。启动来源判断只在本机处理。
- 保留聊天、助手、提供商、模型目录和现有设置；数据迁移版本保持 223。

## 升级与备份

- 安装对应平台的更新包即可覆盖升级；升级前可通过数据设置保留本地备份。
- 开机启动与静默启动沿用原有设置，无需重新创建登录项。

## 验证范围

- 本机已完成选择器及启动设置的针对性测试、类型检查、前端构建和 stable Rust 测试；未调用真实模型。
- 完整回归、Android API 31／36 设备检查及三平台构建结果见本版本 GitHub Actions。

## 待用户验收与已知限制

- 在默认及最窄快捷窗口中选择长模型、提供商名称，确认新话题按钮始终可见、可点击，顶栏不出现横向滚动。
- 开启开机启动和静默启动后重新登录，确认仅保留托盘；从 Finder、Dock 或托盘主动打开应正常显示主窗。关闭静默后再次登录，应正常显示主窗。
- 本轮未代替用户重启或注销；实际登录时的窗口与焦点表现，以及 Windows、Android 实体设备交互，仍待用户验收。
