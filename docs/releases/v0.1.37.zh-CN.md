# lich13studio v0.1.37

发布日期：2026-10-16

本版本为安全加固版本，不新增产品功能。

## 安全加固

- **桌面端凭据改存系统凭据库**：服务商 API Key、WebDAV 密码与认证请求头改为保存在系统凭据库（macOS 钥匙串、Windows 凭据管理器、Linux Secret Service），本地普通数据只保留引用。Android 继续使用 Keystore。
- **启用生产 CSP**：桌面与 Android 网页层启用内容安全策略，禁止 `eval`，脚本仅允许应用自身资源；同时关闭全局注入的 Tauri API，改为按需显式引入。
- **原生网络请求校验**：模型服务商与 WebDAV 请求只允许 http／https，禁止在地址中携带用户名密码；用户填写的域名若解析到本机回环、链路本地或云元数据地址会被拒绝（防 DNS 重绑定），直接填写的 `localhost`／IP（如本地 Ollama、局域网 WebDAV）不受影响；重定向同样校验；`Host` 等由传输层管理的请求头不再允许覆盖。
- **打开链接与路径更严格**：外部链接只允许 http、https、mailto、tel；`javascript:`、`file:`、`intent:` 等一律拒绝。桌面“打开路径”只接受存在的绝对路径（Obsidian 导出链接除外），Android 只打开允许的链接。
- **CCswitch 导入限额**：单个导入链接超过 8192 字符、单个参数超过 2048 字符，或待确认的导入超过 8 条时直接拒绝并提示，不记录链接内容；合法的 `ccswitch://v1/import` 链接行为不变，仍需手动确认。
- **本地 API 服务**（Electron 遗留代码）：仅允许监听回环地址，CORS 只放行应用自身来源，密钥比较不再泄露长度。

## 依赖与合规

- 通过补丁／次版本升级及 pnpm overrides 修复大部分 npm 安全告警（355 → 45，其中高危／严重从 159 降至 24 且均为需主版本升级或上游无修复的遗留依赖），升级 rustls、quinn-proto、rustls-webpki 等 Rust 依赖补丁版本。
- CI 中高危／严重依赖告警改为阻断；暂无法修复的条目逐条登记。各 CI job 增加超时。
- 补充 `@ai-sdk/*` 补丁依赖所引用的 Apache-2.0 许可证全文。

## 升级提示与兼容性

- 覆盖安装即可。首次启动时，桌面端会把已有凭据迁移到系统凭据库：**只有安全写入成功后才清除本地明文**，失败时保留原数据，可重复执行，不会丢失密钥。
- macOS 首次访问钥匙串时系统可能弹出授权提示，请选择“始终允许”。
- 若系统凭据库不可用（例如没有 Secret Service 的 Linux 环境），应用保持原有本地保存方式并在日志中警告。
- 普通备份仍默认不含凭据；持久化版本仍为 223，备份格式与 CCswitch 导入格式不变。
- HTML 代码块预览受 CSP 约束，预览内容中的内联脚本和外部脚本将不再执行（静态 HTML／CSS 预览不受影响）。
