# lich13studio v0.1.40

## 精简与性能

- 深度清理已下线功能残留（绘画、笔记、Agent、代码工具、调试追踪、富文本编辑器、未挂载设置页与孤立依赖），移除无效的桌面端代理表单、数据目录假迁移与 Markdown 默认导出目录设置。
- 启用兼容 Android 12 系统 WebView 正则能力探测的 `esbuild` 压缩，收敛代码高亮至单一 Worker 实例并按需加载公式、图表、文档解析与历史迁移模块，大幅降低构建体积与双窗口冷启动开销。
- 原生运行时改用事件唤醒取消机制、短周期安全连接复用池、窗口状态防抖落盘与流式备份打包，降低 CPU、内存峰值与磁盘写入开销。

## 修复与安全

- 修复 PDF 附件多模态发送参数损坏、流式输出空闲帧空转、历史搜索全表加载内存尖峰、切换话题草稿串台、导出保存框取消误报提示及 Token 估算修改原消息列表的问题。
- 下线自动连接外部服务的 PlantUML 代码块在线预览；补齐 Android 中断流队列回收、备份恢复异常回滚解锁、WebDAV 与本地备份文件名校验，以及删除附件与重置数据时的磁盘文件清理。
- 持久化版本保持 223，已有服务商、系统凭据、助手、聊天记录、模型目录与备份格式保持兼容。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
