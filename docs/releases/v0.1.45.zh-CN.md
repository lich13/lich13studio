# lich13studio v0.1.45

## 快捷窗口与面板定位修复

- **桌面端切换原生 WebView 缩放**：桌面 Tauri 主窗口与快捷窗口改走原生 `Webview.setZoom` 并跨窗口实时同步，移除 `<html>` CSS `zoom`，根除缩放比例非 `100%` 时的下拉菜单与浮层坐标偏移。
- **快捷助手顶栏选择器防裁切与几何保持**：为「模型」与「服务商」下拉框补齐视口自动平移钳制（`shiftX`／`shiftY`）与紧凑弹窗宽度，保留虚拟列表顺畅滚动并补齐弹层禁拖区；快捷助手无锚点重开时保留屏内已拖拽位置，原生文件弹窗期间挂起失焦自动隐藏竞态，暂停或中断流式生成时完整落库已输出末段正文。
- **输入栏快捷面板（`QuickPanel`）锚定与交互修复**：将 `/`、`@` 快捷面板锚定于输入框正上方，按可视视口剩余高度动态钳制列表高度，修复模糊匹配跨项漏筛、滚轮滚动阻断与超长标题挤压重叠；收紧快捷助手 `'c'` 键复制守卫，修复上下文 Token 计数点击重置与剪贴板预览关闭热区。

## 全栈性能优化与资源瘦身

- **原生流式 HTTP 微批与连接池收敛**：流式响应分片增加最多 `16 KiB`／`4ms` 微批聚合（正常结束即时冲刷尾包，取消时立即丢弃未发缓冲以严格保持停止语义），大幅降低高频 SSE 跨端事件开销；无空白 Base64 载荷直解字节切片，收紧空闲连接池上限。
- **零 AST 流式备份与原位加解密**：本地备份、便携导出与 WebDAV 备份去除 `serde_json::Value` 整树反序列化，改经流式结构校验直写 ZIP；加密备份预留 37 字节头部原位加解密（双向兼容 `v0.1.44` `LICH13BK\x01` 容器）并支持桌面端先选保存路径再加密落盘，对齐本地列表与便携入口的大体积加密归档恢复上限；普通磁盘附件内存缓存上限收紧至 `16 MiB`，恢复结束后即时释放临时 `memory://` 缓存。
- **前端渲染、状态与包体精简**：修复模型目录 IndexedDB 缓存启动即时安装与入参深冻结隔离、流式代码高亮节流与回退竞态、Shiki 主题切换静态代码块重高亮、话题请求队列空闲回收竞态及历史搜索实时话题投影；按需动态加载旧版 WebView `core-js` 补丁、图表预览与拼音库，开启 Rust Release `lto = "thin"` 与 `codegen-units = 1`。
- **Android 与桌面宿主加固**：将 Android SAF 文件导出拷贝移至后台线程消除主线程阻塞，补齐临时导出文件清理守卫、本地备份删除前缀与非符号链接校验，以及主窗口几何状态单任务防抖落盘。

## 架构精简与残留清理

- **深度减法治理**：移除退役静态模型表、孤立工具模块、零调用 Redux reducer、废弃样式表与过期架构文档，全路径幂等清理退役 `llm.settings` 影子对象，同步剔除未引用多语言词条。持久化版本保持 `223`，完全兼容既有数据与备份。

## 安装包

提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
