# lich13studio v0.1.39

## 修复

- 修复 Android 12 系统 WebView 启动失败：保留语法高亮依赖的正则能力检测，避免构建压缩错误判断浏览器支持范围。
- Android 回归测试通过普通服务商设置准备凭据，覆盖地址保存、模型与服务商选择、凭据保护及进程重启。
- 更新 Markdown、数据校验、TLS 证书和 ZIP 依赖，修复依赖审计中的阻断告警；删除已无运行用途的 Mistral SDK 与 Undici。

## 功能与数据

- 延续 v0.1.38 的移除结果：CC Switch 链接接管、模型测试及其专属状态与缓存已退出应用；Electron 主进程、兼容源码和专属依赖已删除。
- 保留 React 界面与 Tauri／Rust 原生运行时，以及正常聊天、服务商、凭据、助手、聊天记录、模型目录和备份。
- 持久化版本保持 223，现有备份格式保持可用。

提供 macOS Apple Silicon DMG、Windows x64 安装程序和 Android ARM64 APK，并附 SHA256SUMS。
