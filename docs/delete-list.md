# 删除范围与保留边界

初始精简计划已完成。已删除功能包括模型测试、链接导入接管、内置翻译、知识库／RAG、助手市场、MCP、网页搜索、健康探测和手机导出服务器；相关孤立实现、依赖、无引用文案及补丁在仓库收敛时继续清理。

以下不是按关键词删除的对象：

- 历史数据库迁移、旧消息类型和持久化键。
- OCR 的语言定义与界面国际化。
- `vite.config.ts`：负责主窗口和快捷助手的 React 构建。
- `build/tray_icon.png`等原生层实际引用的资源；正式应用图标由 `src-tauri/icons` 提供。
- `resources/skills`：维护工具和许可来源继续保留；原生层未使用的旧安装脚本已删除。
- 第三方许可证、来源说明、供应商模型元数据与公开包导出。

候选扫描使用 `knip.json` 标明动态入口，结合 depcheck、cargo-machete 与实际引用判断。扫描结果不是删除授权；空 catch、常量 unwrap 和测试断言也须逐处核验。
