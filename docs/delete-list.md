# 删除范围与保留边界

初始精简计划已完成。已删除功能包括内置翻译、知识库／RAG、助手市场、MCP、网页搜索、健康探测和手机导出服务器；相关孤立实现、依赖、无引用文案及补丁在仓库收敛时继续清理。

以下不是按关键词删除的对象：

- 历史数据库迁移、旧消息类型和持久化键。
- OCR 的语言定义与界面国际化。
- `electron.vite.config.ts`：仍负责当前前端构建。
- `build/tray_icon.png`、窗口及兼容托盘实际引用的资源；正式应用图标由 `src-tauri/icons` 提供。
- `resources/skills`、内置代理模板和安装脚本：存在动态路径调用。
- 第三方许可证、来源说明、供应商模型元数据与公开包导出。

候选扫描使用 `knip.json` 标明动态入口，结合 depcheck、cargo-machete 与实际引用判断。扫描结果不是删除授权；空 catch、常量 unwrap 和测试断言也须逐处核验。
