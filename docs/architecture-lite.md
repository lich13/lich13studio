# 运行架构

桌面和 Android 使用 Tauri 处理窗口、文件、备份、原生 HTTP。React renderer 负责助手、话题、消息和模型选择。界面通过原生桥接调用 Rust 命令，普通 Vite 只构建主窗口与快捷助手；无 Node 侧车或 Electron 运行时。

## 模型请求

平台为 `openai | grok | anthropic`，协议为 `openai-response | anthropic`。平台目录集中保存型号，运行时与选定提供商组合。选择失效时提示修正，不替换提供商。`settings.chatRequestMode` 控制普通聊天流式／非流式，发送时冻结模式与目标。

AI SDK 构建请求，原生 HTTP 传输；用户取消会结束当前连接。模型请求无应用层超时。五档推理强度默认 max，仅明确拒绝档位且尚无内容时在同一目标降级；Anthropic 按能力映射，预算低于输出上限。

## 目录与持久化

三平台目录和 CLI 身份分别同步公开官方来源，不访问服务商 `/models`，不携带服务商凭据。共享端点规则保留子路径和显式完整端点。用户编辑、排序、删除记录与当前选择不会被同步覆盖。

业务持久化版本为 223，启动与恢复共用幂等规则，见 [迁移说明](migration-notes.md)。已移除功能的历史记录仍只读兼容。

## Android 与备份

`RuntimeCapabilities` 隔离桌面能力。Android 原生层处理系统栏、键盘、SAF 和前台服务。后台任务租约覆盖聊天；通知 Stop、服务终止、退出推进取消 epoch 并释放连接和唤醒锁。256 KiB／128 事件有界确认队列在 WebView 恢复后重播未确认事件，旧事件不得恢复停止任务。系统杀进程后不自动重发。

Android 普通状态只存凭据引用，Keystore 加密写入成功后再清除明文；桌面使用系统凭据库，普通持久化只存引用；安全存储不可用时的边界见 [隐私说明](privacy.md)。备份默认排除凭据，含凭据时采用版本化 Argon2id／AES-256-GCM 容器，随机 salt／nonce 独立，认证和结构校验先于恢复。附件单独暂存，失败回滚。

## 检查

本地和 CI 使用 `pnpm run ci` 的同一前端／Rust 检查定义。请求、生命周期、迁移和备份测试采用虚拟接口；Android API 31／36 设备检查由独立 instrumentation APK 执行。通过项以实际日志为准，不将构建成功等同于功能验收。
