# 当前功能范围

初始精简计划已完成，本文按 0.1.43 更新；历史方案可在 Git 历史中查阅。

保留助手／话题／聊天、模型与提供商选择、三平台共享目录、快捷短语、图片附件、本地及 WebDAV 备份。桌面保留托盘与快捷助手，Android 提供底部导航、系统文件选择、后台任务通知以及 `ccswitch://v1/import` 服务商连接接管与粘贴导入（桌面端不注册 `ccswitch://` 协议）。

平台为 OpenAI、grok、Anthropic；协议为 Responses、Anthropic Messages。没有预置服务商，不进行连接探测，不从第三方服务商拉取模型列表，不自动替换请求目标。

已删除模型测试、桌面端自定义协议接管、内置翻译、知识库／RAG、助手市场、MCP、网页搜索、健康探测和手机导出服务。OCR 语言配置、界面国际化、旧消息只读展示与历史迁移不是这些功能的运行入口。

持久化版本保持 223，兼容现有备份容器、系统凭据与聊天选择。Electron 主进程、preload、旧 WebView 容器及专属依赖已删除，React 界面继续使用 Tauri／Rust 原生能力。
