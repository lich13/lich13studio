# 当前功能范围

初始精简计划已完成，本文按 0.1.34 更新；历史方案可在 Git 历史中查阅。

保留助手／话题／聊天、模型与提供商选择、三平台共享目录、快捷短语、图片附件、ModelTrace、本地及 WebDAV 备份。桌面保留托盘与快捷助手，Android 提供底部导航、系统文件选择与后台任务通知。

平台为 OpenAI、grok、Anthropic；协议为 Responses、Anthropic Messages。没有预置服务商，不进行连接探测，不从第三方服务商拉取模型列表，不自动替换请求目标。

已删除内置翻译、知识库／RAG、助手市场、MCP、网页搜索、健康探测和手机导出服务。OCR 语言配置、界面国际化、旧消息只读展示与历史迁移不是这些功能的运行入口。

本轮仓库收敛不新增产品功能，不改变持久化版本 223、备份容器、CCswitch 行为或现有选择。尚有兼容的 Electron 源码及上游包接口，不据此重新启用产品入口。文件删除以真实调用和打包关系为准。
